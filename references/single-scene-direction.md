# Single-scene Direction

用于 Lane A 单场景和 Lane B 中需要单独精修的镜头。这里保留可迁移的导演规则，不保存某个模型的固定时长、格式或审核绕行技巧。

## 1. 静默盘点

写 Prompt 前确认：

- 主体：用户明确的人物、产品或物体；
- 场景：室内/室外、空间关系、时辰和主光；
- 道具：镜头真正使用的物件；
- 风格：色板、媒介、材质和摄影质感；
- 用户指定的机位、动作、台词和结束状态。

改编任务不得无中生有核心人物、地点、产品或道具；原创任务可以补齐环境与行动细节，但仍要说明推断。

不要把“隐藏年龄词”当通用质量规则。用户明确年龄且内容合规时应保留必要信息；只有年龄与镜头无关时，才用服装、身份、轮廓和动作等可见特征代替。

## 2. 选择场景原型

原型用于决定什么在变化，不是固定模板。

| 原型 | 核心变化 | 建议摄影任务 |
|---|---|---|
| Pursuit | 追逐距离和路径 | 跟拍、侧跟、空间收窄/打开 |
| Duel | 双方优势交替 | 中近景交替、明确屏幕方向 |
| Impact | 铺垫 → 接触 → 余波 | 接触点清楚、冲击后留 settle |
| Journey | 主体穿越空间 | tracking、并行跟拍、航拍建立 geography |
| Atmosphere | 情绪由微变化承载 | 锁定或极慢推，不靠无意义运镜 |
| Reveal | 隐藏信息变得可见 | pan、crane、dolly 控制观众何时看见 |
| Confrontation | 对峙中的权力交换 | OTS/近景，换位时重新锚定 |
| Interrogation | 不对称提取与抵抗 | 角度、停顿和距离体现权力 |
| Negotiation | 双方都有所求 | 对称 coverage，细节反应证明变化 |

原型不匹配时不用硬套；先回到镜头的 story function。

## 3. 可见动作约束

- 动作写意图、力的方向、接触、反应和余势，不写冗长关节说明；
- 只描述能看见或听见的证据，不写嗅觉、心理或镜头外已发生的变化；
- 连续追踪主体数量由 live provider 的身份区分能力、遮挡/接触复杂度、叙事必要性和最高风险代表镜决定；数量增加时先证明可辨性与状态交接，不设跨题材人数上限；
- 角色出画后，不在同一连续镜头无因重返；
- 反射面会放大身份和空间错误，只有叙事必要时使用；
- 微表演写成下颚、鼻翼、手指、肩膀、呼吸等物理变化；
- 默认把一镜压到最小可读的 camera path 与 visible change；叙事确需相容的分阶段动作或复合机位时可保留，但必须是一条可解释的连续因果/几何轨迹，并先过代表镜。
- 摄影机处在爆炸、坠落或撞击现场时，也按同一空间中的有质量物体处理：写清它受到的冲量、离场方向、旋转余势与重新找回主体的过程。
- 异常物理世界的每个规则边界同时约束人物受力、随身物惯性与摄影机坐标；跨界后的构图要让新受力面读成地面，不照搬其他场景的旋转角度。

开生成前把场景事件、人物动机/目标/阻碍/战术收口到一个可拍物理动作。信息差必须同时拥有观众可见而角色不可得的视点，以及角色不知情地趋近它的动作。识破/认出类转折在克制表演需要时只给一次最小反应，随即转入行动；不把该节拍变成所有表演风格的定额。

## 4. Cut 与空间

每次 cut 后重新声明：主体位置、朝向、屏幕运动方向、道具状态和连续性。

优先做“双对比”：镜头尺寸和镜头性格至少同时改变，例如手持中景 → 锁定近景。因果 insert 可以短，但要写清是谁的手、物件或表面，以及为什么此刻切到它。

不要把“双对比”机械套到故意保持对称、匹配剪辑或连续动作的镜头；此时以叙事用途和可剪性为准。

## 5. 对白密度

生成式短镜头只保留能改变关系、暴露真相或完成转折的台词。其余信息转为可见动作，或拆成独立 dialogue pickup/后期配音。台词语言、口型和原生音轨都要在目标 provider 的 live schema 中核验。

## 6. 输出

遵守 `prompt-contract.md` 的 Fast / Directed / Production 密度。不要固定双语 JSON、固定 10/15 秒、固定 SFX-only 或固定平台占位符。用户只要 Prompt 时给可复制块；用户要首尾帧、资产或成片时升级到相应 Lane。

## 最小 QC

- 主体、空间和唯一变化是否清楚；
- 镜头是否有物理位置和叙事用途；
- 动作是否有因果、接触、反应和稳定末态；
- 每次 cut 是否能重新建立空间；
- 是否删除了空泛质量词，而不是删除必要事实；
- 是否没有把 provider 假设写成永久能力。
