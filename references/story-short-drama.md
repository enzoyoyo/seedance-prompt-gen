# AI 短剧爆款工艺

## 4.5 定位：爽剧专用工具层

本文件保留的是**冲突／逆转爽剧 Lane** 的深度工具：羞辱、翻盘、当众交易、60 秒节拍与被毙诊断。所有形式通用的张力工具（想要／阻力／代价／升级／转折、开场四法、升级阶梯、剧本张力门）已移至 `dramatic-tension-engine.md` 并成为默认硬门；标题手艺移至 `title-craft.md`。形式自由，张力不自由：创意先服从 `open-creative-director.md`，人味验收服从 `human-texture-and-script-gate.md`，张力验收服从 `dramatic-tension-engine.md`。

下文的欲望式、三候选、字面标题、2 秒动作、60 秒节拍和羞辱／翻盘门，只在模型明确选择冲突／逆转爽剧 Lane 时作为可选强工具。它们不否定安静怪谈、生活观察、视觉喜剧、关系微变、非线性、氛围、意象标题或无反转作品。这些形式同样必须通过 `dramatic-tension-engine.md` 的剧本张力门，只是不必用羞辱、翻盘或 60 秒结构来回答。资产版本、参考职责、首尾状态、物理连续性、真实末帧、Prompt、Provider 和实像 QC 等技术要求仍是硬约束。

## 边界与防火墙

这份参考聚焦 AI 短剧如何从人性冲突变成可生成、可剪、可发布的目标画幅成片。

- 只读取当前 brief、用户本轮素材、公开参考样本和本 Skill 的 AI 视频参考。
- 不把跨会话无关题材或外部预设设定混入当前人物、场景、对白与案例。
- 这里的创作方法只服务短剧欲望、视觉钩子、资产连续性、运动生成、声画后期和发布回写。

`xyq-short-drama-skill` 只承担小云雀短剧后端的提交、轮询、下载和 WebUI 交接；创意与生产方法仍由本文件负责。

## 爆款欲望轴：交易、羞辱、翻盘、代价

短剧不是从题材标签开始，而是从一桩正在发生的欲望交易开始：

```text
谁现在想从谁手里拿到什么
→ 他拿什么人、关系、尊严或利益交换
→ 对方怎样当众压价、拒绝或夺走
→ 主角用哪一个动作让关系翻面
→ 这次翻面让谁付出什么可见代价
→ 爽点具体兑现在哪一帧
```

这不是要求每条片都套六段，而是要求所有加码围绕同一个欲望产生因果。

## 选题：先杀同款，再写剧本

欲望轴解决“这场戏怎么成立”，不解决“为什么是这个故事”。只有方向空间仍很大、选错方向会重写整部作品时，写全本之前才做候选比较：

- 内部比较足以覆盖真实方向差异的少量候选；数量由 brief 的不确定性决定，不为凑数制造换皮方案。每个候选说明“观众在等待什么”以及与同类作品的实质差异。
- “同款一句话测试”是拥挤题材的预警，不是自动死刑；若一句概括抹掉了本作独有的人物选择、形式体验或代价，就继续推进，否则重做发动机。
- 当前模型默认自主选择最适合 brief 的方向并说明理由；只有用户要求看方案，或存在会实质改变作品且无法从上下文推断的选择时，才把候选交给用户决定。用户已点名题材时不额外强造候选。

### 饱和度与代入感：红海题材提高门槛

同款测试杀模板句式，杀不掉红海题材。离婚出轨、赘婿逆袭、战神归来这类供给过剩的题材，观众看开头就猜到结尾，猎奇立不住：要么换题材，要么给出该题材从未有过的轴心。

- 目标是广谱共鸣时，可优先从公共压力或普遍关系经验寻找入口；目标是私密观察、类型悬疑或特定圈层时，私人处境同样可以成立。
- 不按“公共／私人”自动升降级；检查具体压力能否被目标观众理解，以及人物是否有不可替代的选择。
- 反转优先落在人心的复杂（明知对方图钱照样给、到手的钱当面拒），不落在信息差的聪明人游戏——后者观众隔岸观火，不站队。

### 三观炸裂＝吵起来，不是坏给你看

当本集的观看发动机就是价值冲突时，可设计一个两边各有自利逻辑、观众能争论的判断点；纯动作危机、悬疑揭示、黑色喜剧或其他发动机不必硬塞道德辩题。单向恶、勒索或骗局若只是阶段性动作，应继续追问它如何迫使人物选择，而不是用标签替代人物。

### 被毙之后：先诊断死在哪一层

用户说“重来／太差”时，禁止在原稿上抛光台词交差。先把死因定位到四层之一，再动笔：

```text
题材轴　　观众看开头猜到结尾、没有代入欲 → 重新摆候选换欲望式，原稿只留可用零件
故事结构　反转靠证据掉马、承诺不兑现　　 → 重排事件链，人物动机不动
场景节拍　有划走点、中段节奏塌陷　　　　 → 只动 BEAT 顺序与信息释放时机
台词表演　不像人话、潜台词失效　　　　　 → 逐句替换，结构不动
```

连续两稿死在同一层，说明方法没换：回到上一层推倒，不做第三次同类修补。每次交新稿附一句“这次改的是哪一层”，让用户校验方向，而不是逼他逐句找茬。

### 片名：按 title-craft.md 交付

片名机制、三测、≥5 候选与选 1 备 2 的输出格式见 `title-craft.md`；本 Lane 偏好字面钩子，但仍按同一套三测验收。

### 欲望必须能拍

“想要尊重”“想证明自己”太抽象。把它改成眼前能争夺的动作：拿回钥匙、坐上那个座位、让对方当场改口、带某个人离开、拒绝签字、收回送出的东西。欲望一旦可见，镜头才知道该盯谁的手、谁挡住路、什么东西改变归属。

### 翻面动作先过生成可行性

欲望可见还不够，翻面应落到可被镜头证明的行动或结果。身体动作通常更容易生成；若手机、转账、合同、监控或界面本身是故事不可替代的证据，可把精确文字交给确定性后期，再生成角色对证据的动作与反应。选题期预估说话者、连续空间、屏幕文字与交互复杂度；不设通用数量上限，但超出当前模型稳定能力时要拆 coverage、pickup 或 post insert。

### 交易让人物暴露自己

交易不限于钱。角色可能拿沉默换体面、拿关系换机会、拿别人承担的损失换自己的安全。先写清双方各自的报价与底线，再写谁先假装不在乎。交易的价值在于迫使人物选择，不在于展示复杂规则。

### 当众羞辱要有见证者与状态变化

“被骂了”不够。要让羞辱在空间里发生：座位被撤、礼物被退回、名字被划掉、门在身后关上、旁人停止说话或换到另一边。见证者不必多，但必须让观众看见人物的社会位置下降。

### 关系翻面靠行动，不靠资料揭晓

翻盘发生在一个动作重新分配权力时：被赶走的人拿走真正不可替代的东西；一直求人的人停止求；旁观者站到另一边；对手不得不使用刚刚羞辱过的人。单纯显示新身份、弹出系统通知或念一份文件，只是信息变多，不是关系翻面。

### 可见代价让爽点有重量

翻盘之后必须有东西不能复原：关系破裂、机会丢失、秘密被本人承认、主角也失去原本想保住的东西。没有代价的碾压像演示片；代价落到画面里，观众才相信人物真的跨过去了。

### 旧解谜引擎的开放使用边界

隐藏系统、道德账本、档案、合同、监控、日志、身份资料和“机关式掉马”不再是本 Lane 的默认发动机；但用户点名或当前作品确需时可以成为核心机制。此时仍要让人物欲望、选择、后果或题材自身因果独立成立，不得只借旧案例的资料掉马公式推进。

## 开场 2 秒：先给可见利害

第一帧不介绍世界，先把人物扔进一场已经开始的戏。

一个可拍的 0–2 秒开场通常同时具备三项：

- 一个正在发生的不可逆动作：撕、推回、摘下、锁门、带走、坐下、倒掉、按住；
- 一个清楚的权力差：谁站着、谁被围住、谁控制门/座位/关键道具；
- 一个眼前损失：再晚一步会失去什么，或哪段关系正被公开定价。

先关掉对白、字幕、手机文字和旁白看一遍。静音时仍要读懂谁在逼谁、争的是什么、哪一步会让关系变化。若必须先读合同、背景介绍或世界规则才能明白，开场还不是戏。

开场提出的承诺必须在本集兑现：开头让观众等一场当众反击，结尾就要看见反击动作及其代价；不能只留一句“真正的好戏才刚开始”。

## 人物卡：既能演，也能锁资产

每个主要人物都写两层，避免“会写但不能生成”或“长得稳定但没有戏”。

### 表演层

```text
眼前欲望：这一分钟非拿到不可的东西
公开姿态：他希望别人以为自己是什么样
真正底线：宁可丢掉什么也不肯承认什么
惯用动作：紧张、讨价、撒谎、压人时会做什么
翻面动作：哪一个动作意味着他不再接受旧关系
代价反应：代价落到自己身上时身体先怎样变
```

伤口与背景不直接讲给观众听，只通过报价、回避、误伤、停顿和选择显露。

### 资产层

冲突／逆转 Lane 仍服从 [keyframe-assets.md](keyframe-assets.md) 的最小充分资产规则：

1. 高复用或高漂移角色先锁身份与服装；换装、破损、污渍各建独立状态。
2. 先列实际镜头会辨认的视角、比例与细节，再选择单图、分图或适当 panel；Sheet/3-panel 不是默认仪式。
3. 一次性背影、不可辨认群众或只承担轮廓职责的人物，只建下游真正需要的资产。

角色图只需让下游镜头辨认所需身份、比例与衣料结构；强戏剧光、浅景深和情绪终态留给场景关键帧，不烘焙进身份真源。

## 对白：短、打断、潜台词

对白的职责是争夺，不是说明。每一句先标一个动作目的：试探、压价、遮掩、拖延、拒绝、威胁、求饶、挽回、逼对方表态。找不到动作目的的句子，多半可以删。

### 写人话的四个动作

1. **砍完整句。** 人在冲突里不会把背景、原因和立场一次说完；删掉主语、解释和结论。
2. **让答复错半拍。** 对方可以答非所问、重复一个词、反问、转向道具或故意叫错称呼。
3. **用打断改变权力。** 打断不是加破折号装口语，而是有人夺走说话权，迫使另一人改策略。
4. **让动作说完后半句。** 推回杯子、收起椅子、拔掉充电线、把门留一条缝，往往比主题发言更狠。

对照：

```text
说明书式：你三年前抛下我，所以我今天绝不会再相信你。
人话：
“我来接你。”
她没抬头，把第二只碗收回柜里：“一只就够。”
```

第二版不用把潜台词解释回来。只要前后动作、称呼、停顿和物件归属能让观众听懂，就别补“其实我的意思是”。

### 朗读与静音双修

- 朗读时一口气说不完的句子先拆；演员没有动作空间的连续台词先砍。
- 删掉“如你所知”“这一切都是因为”“我之所以”“我终于明白”等作者代言句。
- 把能由视线、座位、手部、距离和道具表达的信息移出对白。
- 静音仍懂冲突，开声后对白再增加性格、误会和压力，而不是重复画面。

### 快节奏冲突 Lane 的抒情失焦自查

以下只检查本来承诺强冲突、快速兑现的作品是否被无功能抒情稀释；氛围、观察、诗性、怪谈或其他把停顿和意象作为发动机的作品不使用这组禁令。

- 静物或空镜若不能让观众读出正在变化的关系、威胁、时间或感官模式，就删；若它本身承载观看承诺，可以保留。
- 回忆若不改变当下人物的选择、认知或感受，只提供泛化怀旧，就压缩或移除。
- 意象道具要在本作中获得具体关系，可通过动作、反复、声音、空间或视角建立，不要求一律成为武器或筹码。
- 结尾应兑现、深化、释放或有意重构开场承诺；认知颠覆和新危机只是冲突 Lane 的可选结尾，不是唯一答案。无论哪种结尾，都要留下具体的未付代价或未答问题，不留口号。

### 爽点与关系同步升级

爽点可从小反击走向阶段胜利、关系/身份翻转与终局兑现，但只作本 lane 的菜单；它与压迫阶梯是正交轴，压力增加时兑现也要实质增加。压力驱动的爽剧若把配角长期写成单向受压工具，可在同一关系线上加入有铺垫的立场转向；非爽剧不强加“先压后和”。

## 冲突 Lane 60 秒写作参考（可选）

以下是写作参考区间，不是平台规则，也不是每条必须卡秒：

**写作参考区间，不是交付时长。** 实际交付时长由 brief 与当次平台规则决定。

目标命中该条件模块后，平台画幅、交付时长与实时查询统一读取 [platform-douyin.md](platform-douyin.md)；本节不保存平台默认或查询模板。

| 时间 | 冲突 Lane 常见任务 | 可选写作动作 |
|---|---|---|
| 0–2s | 人物、权力差、眼前损失 | 直接做一个不可逆动作 |
| 2–8s | 谁想要什么、谁握着它 | 用最少信息建立欲望与阻力 |
| 8–20s | 第一轮交易或拒绝 | 双方报价，主角先吃亏 |
| 20–35s | 当众加压或关系恶化 | 同一欲望变得更贵，不开新支线 |
| 35–48s | 人物主动做出翻面动作 | 旧关系被重新分配，不靠旁白宣布 |
| 48–57s | 爽点兑现与可见代价 | 给反应、余波和无法复原的证据 |
| 57–60s | 一项尚未付完的具体代价 | 用动作收尾，为下一条留下眼前问题 |

一集只推进一个中心事件。若 60 秒里装不下对白与反应，先砍背景，再把一个动作拆成两个 clip；不要让角色用倍速把故事念完。情绪翻面后留出可见的处理拍，让人物咽下去、松手、退半步或看向见证者。

连载也要让每条新观众看懂眼前交易。上一集只提供余势，不要求观众背设定；这一集先兑现一个局部承诺，再把仍在增长的代价传下去。

## 从剧本到可生成

### 1. 人物卡变成角色资产

把每个适用角色的表演层与当前 approved 身份、服装和最小 view-set 资产 ID 对上。当前场次使用哪套服装、是否破损、拿着什么道具，都写进镜头起止状态，不靠 Prompt 临时回忆。

### 2. 场景变成可走位空间

只锁会改变本场 blocking、可达性、证据或连续性的空间维度，例如入口/出口、遮挡、景深层、关键座位/台面、主光来源或正反打方向；无关项不强填。场景资产要能回答当前戏真正依赖的空间问题。

### 3. 道具变成状态证据

对每个反复道具记录初态、谁持有、何时易手、是否破损、终态和所需视角。交易、羞辱、翻盘或代价如果依赖它，就给它近景证明；不能在镜头外凭空出现、恢复或换主人。

### 4. 只画决策分镜

优先画本作真正决策关键的关系、动作、落点、反应或余波。每格保留镜头作用，以及会改变生成/剪辑的适用景别、人物位置、屏幕方向、道具状态、continuity in/out 或下一剪接点；无关字段删除。把格子按本作的感官/因果逻辑连读，再补漂亮镜头。

### 5. 在边界控制值得时生成首尾关键帧

首尾帧只有在起止边界、接力、转场或循环控制确实降低风险且 live 模式支持时才使用。使用时，首帧锁当前动作起因、适用站位/方向/状态/运镜起势，尾帧锁动作后的适用稳定姿势、道具位置、运镜落点或可剪辑 hold；两帧之间必须存在连续身体与物理路径。换装、重伤或跨时空变化应拆镜，不做硬插值。

### 6. 把镜头写成运动 Prompt

静帧已经说明“是什么”，视频 Prompt 只写“如何变化”：

```text
镜头作用：<这条镜头让关系怎样变化>
起始：<人物、道具、站位和首帧状态>
0–3s：<触发动作 + 第一反应 + 相机路径>
3–6s：<接触/翻面 + 环境或旁人反应 + 运镜落点>
表演：<情绪的身体征兆 → 台词与口型 → 抢话、停顿与视线归属 → 情绪终态>
稳定末态：<身体、道具、光线、空间和可剪 hold>
声音/后期：<对白 pickup、接触声、环境声、字幕或精确文字>
```

片长不同就按动作自然分段，不机械套 3 秒。默认保留最小可读变化与机位轨迹；相容的分阶段变化或复合路径可在一段/一镜共存，但必须有清楚因果、连续几何并通过代表镜。物理动作按需要写清起势、发力、接触、反应、余势与稳定末态。

### 批量生产的提示词合同

一次生成就要可用的流水线，提示词按「常量 + 变量」组织，不为每镜重新发明：

- **共享区只放真实不变量**：跨镜确实不变且已经批准的身份、服装、声音或世界事实可以复用；不要把镜头局部状态或通用负面词库冒充全剧常量。
- **变量区按镜头职责选择**：从当前动作、起止状态、相机、声画、材质与失败风险中保留必要项；台词时间节点只在动作确需与某词同步时使用。材质写可观察的相对关系；固定倍率只是测试过才可采用的实现例，不是默认值。
- **negative 按镜头残余风险生成**：先用正向约束消除风险；仍需 negative 时只写当前 provider 接受且无法正向化的具体项，可省略，不为统一或凑数复制。
- **参数约束先校验再提交**：参考图数量、音视频引用数、prompt 字符上限等只按 exact model/account/endpoint 的当次 live schema 预检；超限时拆镜、裁剪或改用有证据的两阶段路径，不缓存旧限额，也不赌服务端宽容。
- **高风险表演拍才做细审**：按当前失败风险检查功能、前后价值变化、视点、权力变化、人物打法、阻碍、潜台词、可见压抑动作、不可移植细节与明确拒绝的套路；简单动作镜头不为凑表格强填这些项。
- 目标是达到当前剪辑职责所需的可用阈值；小瑕疵能由确定性后期修复就不整段重抽。实际重试次数、成本与失败类型记入 production log，不写无本轮数据支持的固定通过率或成本倍数。

## 首尾帧与参考职责

图像生成解决静态真相：身份、服装、场景几何、道具结构、构图、光线与起止状态。视频生成解决时间里的变化：表演、动作、运镜、物理响应、节奏和声音。不要让视频模型重新发明已经锁好的资产。

| 参考 | 只负责什么 |
|---|---|
| Face Lock | 身份、脸、皮肤、头发、体型 |
| Outfit | 剪裁、结构、材质、颜色、配件 |
| View set（按需） | 镜头实际需要的转面、比例、服装或身份细节 |
| Prop sheet | 道具形状、比例、材质和当前状态 |
| Location plate | 空间关系、建筑、入口/出口和光源方向 |
| Style reference | 色板、纹理、介质，不复制人物 |
| Motion reference | 动作、运镜或节奏中的一项主要职责 |
| First/end frame | 一段运动的起止边界 |
| Relay frame | 上一镜真实留下的当前状态 |

一个参考承担小而相容、可独立验收的职责集合；职责冲突、注意力竞争或超出 live 槽位时再拆。全能参考不是“万能混合”：

- 动作迁移只借动作骨架、速度和节奏；
- 运镜模拟只借机位路径、方向、速度曲线和落点；
- 换背景保留主体动作与机位，只替换命名环境，并重算接触光、遮挡和反射；
- 分镜直出用已选分镜锁顺序与构图，再补帧间运动；
- 片段延长从真实稳定末帧、动作余势和声音尾巴继续；
- 节奏剪辑只借拍点、停顿和 cut rhythm，不借原片人物或 IP 表达。

具体 provider 是否支持、如何绑定槽位，执行前读取 live schema。语义职责先写清，`@图片N`、media flag 或 attachment field 后填。

首尾帧还可用于匹配转场、遮挡转场、甩镜落点和循环。循环的尾态必须能在身体、道具、光线和镜头位置上自然回到首态；不能只把第一帧复制到最后。

## 真末帧接力：下一段吃画面，不吃剧本幻想

一段生成完成后，不默认取文件的最后一帧。逐帧找到身份、手部、道具、光线、空间和动作余势最稳定的画面，把它登记为 relay frame，再作为下一镜的当前状态参考。

- 模糊、闭眼、口型半开、脸被挡、手指变形、道具漂移的帧不能接力。
- 中继帧负责“此刻状态”，Face Lock 仍负责“这个人是谁”。
- 没有可用中继帧，就回到当前镜头重做；不要把缺陷传给下一段。
- 实际结果与剧本略有不同但人物因果更自然时，可顺着真实画面微调下一镜；若爽点、关系或代价被破坏，则修当前镜头。
- 没写过的意外反应——一次甩腿、一句抢话、一个多看的停顿——只要不破坏因果就是素材：留住它，让下一镜接住。把所有意外抹平，得到的只是整齐的演示片。

### 看像素，单变量回修

先生成最难的代表镜头，不先批量做容易镜头。出现问题时找到第一处可见错误，并回到最早的原因：

| 画面问题 | 先改什么 |
|---|---|
| 脸、体型或发型漂移 | Face Lock 或身份职责 |
| 服装结构、配件漂移 | Outfit variant |
| 道具形状、比例、归属错误 | Prop sheet 或镜头状态 |
| 空间无法正反打、光源乱跳 | Location plate 或关键帧 |
| 资产稳定但动作不读 | 运动过程或片长 |
| 动作对但运镜抢戏 | 相机路径与速度 |
| 尾态不能接 | 尾帧、余势或 hold |

每次只替换一个源资产或一条运动/机位语句，再跑同一个镜头。模型、参考、Prompt、时长一起改，得到的只是另一张彩票。模型名、任务 done、生成数量和自信描述都不算证据；只有导出像素能否承担下一剪才算。

## 声画后期与成片切片

- 一镜先保证说话者归属可辨；多人对谈、抢话或重叠对白只有在当次模型与代表镜测试稳定时保留，否则拆成对白 pickup、反应镜或后置配音。
- 用呼吸、衣料、脚步、门锁、杯子、手机震动等接触声证明动作；用环境声维持空间。
- 羞辱落下、关系翻面和代价反应前后可用短暂静音或音乐收束留出观看时间。
- 精确字幕、聊天界面、文件文字、价格、CTA 与法律文案由后期确定性制作。
- 从多个 take 选择最好动作、表情和台词，先把承诺与兑现剪通，再做速度重映射、转场、调色和统一颗粒。
- 切片不得把开场承诺与本集兑现拆到两个视频；每一条都要能独立读懂眼前交易。

## 发布回写

发布数据只回写创作变量，不扩张成账号运营方法论：

- 首屏划走或 1–3 秒流失高：改第一帧的人物关系、争夺物或眼前损失。
- 8–25 秒掉点明显：删背景和解释，让第一轮交易更早失败，让羞辱见证者更清楚。
- 翻面前掉点：主角被动太久，提前一次有效反抗或把代价逼近。
- 翻面后掉点：爽点没有可见兑现，补对手反应、道具易手和不可逆损失。
- 完播高、复播集中：保留那一镜的视觉证据、停顿或误判机制，回写被证据指向的创作变量；它可能是关系、节奏、感官模式、兑现、包装或续看理由，不预设成“钩子”。
- 评论只猜设定、不站人物：谜题抢走了欲望，下一条减少资料揭晓，增加选择与代价。

只与同平台、同账号、相近发行阶段的自身基线比较。平台公开规则、音乐版权与 AIGC 披露在发布前 live 核对，不凭传闻改剧本。

## 小云雀只交接后端

用户明确使用小云雀短剧时，本 Skill 提供当前目标、剧本、人物/场景/道具资产和必要的连续性状态；`xyq-short-drama-skill` 只负责：

```text
提交 → 轮询 → 获取 thread/file list → 下载结果 → 返回本 Skill 看画面与接力
```

小云雀侧若 live schema 与当前故事都适合沉浸式连续生成，可把一个确有连续价值的时空组织为 `continuous_block`；需要精确反应、接触、文字或失败隔离时，再按职责拆为 `covered_scene`、`independent_pickup` 或 `post_insert`。不得把某个旧案例的镜头占比、题材或生成方式提升为默认路由。

不把小云雀服务端流程复制成新的创作方法，不让 adapter 擅自改欲望轴、对白、翻面或结尾，也不把本 Skill 的 Prompt 偷塞进要求“原样转发”的字段。

## 随目标落出的产物

只有明确选择冲突／逆转爽剧 Lane 时，剧本任务才按本文件落出欲望式、可拍的早期利害、完整场次、自然对白、适配实际时长的节拍与爽点／代价落点；其他形态返回 `open-creative-director.md` 与 `human-texture-and-script-gate.md` 的对应产物，不强造羞辱、翻盘或 60 秒结构，但一律先过 `dramatic-tension-engine.md` 的剧本张力门，并按 `title-craft.md` 交标题候选。

交出去前先自己答五问：静音看得懂吗；翻面是身体动作吗；代价看得见吗；对白读得出口吗；一句话会不会被认成同款。答不上来的那条回去重写，不靠格式齐整过关。

进入生成时再按 `production_class / block_mode / declared risks` 增加最小充分资产与控制项：可能包括人物卡、场景/道具状态、决策分镜、关键帧、分段运动 Prompt、参考职责、relay frame、镜头 selects、声音或后期说明；不存在的对象与无用层级删除。

用户要成片或发布时，最终还应有可播放母版、实际目标平台所需的切片/包装，以及发布后由证据指向的创作变量回写。交付范围跟随用户目标，不用一套重模板压所有任务。
