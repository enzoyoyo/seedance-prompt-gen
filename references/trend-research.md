# 热点蒸馏：只为短剧欲望、钩子与视觉节拍服务

## 4.2 适用范围

通用的当前趋势研究先读 `live-trend-intelligence.md`，从官方规则、第一方趋势、当前样本与创作推断中提炼可原创重建的机制。本文件只在已选择**冲突／逆转爽剧 Lane** 后，进一步拆解欲望、羞辱、翻面和短时节拍；其中 2 秒、60 秒和固定 beat 只是适用样本的分析工具；所有形式通用的硬门是 `dramatic-tension-engine.md` 的剧本张力门。

## 用途与记忆防火墙

热点研究在这里不是追题材名，也不是写账号运营方案。它只回答三件事：观众此刻愿意停下来围观哪种欲望交易，前 2 秒什么可见动作能把利害讲清，哪种视觉节拍能让羞辱、翻面与代价在短时长内兑现。

研究只使用当前任务 brief、当轮公开样本、用户本轮素材和可核验来源，不混入跨会话无关题材或未授权外部项目材料。

提炼结果只服务 AI 短剧的欲望句、开场动作、节拍、分镜、Prompt、声画切片与发布回写，不扩写成通用行业报告。

## 看样本时，只拆能迁移的戏剧动作

热门标签只是找到样本的入口，不是产物。打开样本后，逐条记录观众真正看见的东西：

| 要拆的层 | 具体问题 | 可交给剧本的结果 |
|---|---|---|
| 欲望 | 谁现在非得到什么不可？ | 一句可行动欲望 |
| 交易 | 他拿什么换，对方如何压价或拒绝？ | 第一轮攻防 |
| 羞辱 | 哪个动作让人物公开掉价，谁看见了？ | 可见的地位变化 |
| 关系 | 翻面前谁控制谁，翻面后权力如何重新分配？ | 一次行动翻面 |
| 代价 | 翻盘让谁失去什么，哪部分无法恢复？ | 可见损失与余波 |
| 兑现 | 观众等待的爽/痛在哪一帧发生？ | payoff frame |
| 视觉节拍 | 第一帧、第一次接触、第一次停顿、翻面落点如何安排？ | 可拍 beat map |

重点不是“这条很火”，而是：拿掉角色名、题材词、台词和世界观之后，这套关系动作是否仍然成立。如果只剩某个 IP 的标志性设定，就没有可迁移机制。

### 欲望样本的最小记录

在 [live-trend-intelligence.md](live-trend-intelligence.md) 的 `## Maintain a compact evidence ledger` 记录 `source_url / captured_at / platform / region-language` 之外，本 Lane 每条样本额外记六项戏剧内容：谁想从谁手里拿到什么、拿什么交易、当众羞辱的动作与见证者、翻面动作、可见代价、爽点兑现帧。

证据分级、采样到机制稳定、平台事实与创作推断分离，一律按 `live-trend-intelligence.md` 的 `## Evidence hierarchy`、`## Sample until the mechanism stabilizes`、`## Separate platform fact from creative inference` 执行，本文件不复述。实时查询模板与证据升级规则见 [platform-risk-and-compliance.md](platform-risk-and-compliance.md) 的「## 平台证据门」；本文件不保存查询模板或当期结论。

## 0–2 秒钩子：研究第一帧，不研究口号

对每条样本先静音，只看前 2 秒：

1. 第一帧出现了谁，谁占据更高的位置或更大的画面权力？
2. 哪件物品、座位、门、手势或身体距离说明双方在争什么？
3. 第一个不可逆动作是什么？
4. 即使看不到字幕，观众能否判断谁可能马上失去什么？
5. 开场承诺的羞辱、翻面或危机，后面是否真的兑现？

可迁移的钩子不是“震惊”“你绝对想不到”，而是一个正在改变关系的动作。例如：东西被当众推回、位置被别人占走、门被从里面反锁、礼物被拆给另一个人、原本求人的一方把手收回。研究时只抽取动作机制，创作时重建人物、物件、空间与因果。

### 视觉节拍拆法

把样本压成不依赖对白的短序列：

```text
第一帧关系
→ 欲望物出现或易手
→ 一方公开压价/拒绝
→ 主角的第一反应
→ 行动翻面
→ 对手与见证者反应
→ 可见代价和稳定余波
```

若样本靠长背景、文件文字、系统设定或旁白解释才成立，只把它当反例，不把“信息多”误判为钩子强。

## 学机制，不抄 IP

允许学习：

- 第一帧如何把人物、权力差和争夺物放在同一画面；
- 交易怎样升级，拒绝怎样公开化；
- 哪个动作让关系翻面；
- 爽点前后留多少反应与余波；
- 开场承诺如何在本集得到兑现；
- 竖屏如何用近距离、前后层次和手部特写提高静音可读性。

禁止复制：

- 专有角色名、世界观组合、身份设定和关系组合；
- 标志性台词、独特道具、连续镜头顺序和辨识度高的美术签名；
- 对某条爆款的同场景换脸、同桥段换职业、同对白改几个词；
- 把“豪门、重生、复仇、AI、甜宠、悬疑”等题材词拼成创意。

原创重构至少同时改变欲望对象、关系结构、交易筹码、发生空间、翻面动作和可见代价，并重新证明这组人物为什么会做出这些选择。换名字不算重构；拿掉热门标签后冲突仍能成立，才说明机制已经独立。

## 研究结果要直接喂给剧本

一轮研究最终只需要落出能写戏的内容：

### 1. 一句欲望式

```text
<人物> 现在要从 <关系对象> 手里拿到 <具体东西/行动>，
拿不到就会 <眼前损失>，他准备拿 <筹码> 去换。
```

### 2. 一帧钩子

写成可拍画面，不写传播口号：人物位置、正在发生的动作、关键道具、谁控制空间、眼前损失。

### 3. 一条视觉节拍

把上面两项落到 [story-short-drama.md](story-short-drama.md) 的 `## 冲突 Lane 60 秒写作参考（可选）`，用那张表的时间段填本轮的可见动作；本文件不再复制节拍表。时间是写作范围，不是平台常量；实际长度跟随动作可读性与目标渠道当前规则。

### 4. 原创差异说明

用两三句说明新版本改变了哪些人物因果和视觉系统，以及为什么不再依赖原样本的 IP 表达。若仍能一眼对号入座，继续换机制，不进入剧本。

### 5. 要测试的钩子变量

一次只改变一个开场变量，例如第一帧道具、不可逆动作、见证者位置、第一句是否保留或翻面提前多少。不要同时换题材、角色、节奏和包装，否则发布结果无法回写创作。

## 用划走与完播回写钩子

回写方法与比较口径按 [live-trend-intelligence.md](live-trend-intelligence.md) 的 `## Feedback after publication` 执行（只和同账号、同平台、相近发行阶段的自身样本比较，不使用统一完播线或传闻算法权重）。本文件只给冲突 Lane 的信号→工艺映射：

- 首屏划走或 1–3 秒流失高：第一帧的关系、争夺物或眼前损失不够可见；先重拍钩子。
- 8–25 秒掉点：解释太多或第一轮交易没有失败；删背景，让压价/拒绝更早发生。
- 翻面前掉点：主角长期被动，观众看不到他会如何选择；提前一次有效反抗或缩短受辱时间。
- 翻面后掉点：爽点只是台词宣布；补道具易手、位置变化、对手反应与不可逆代价。
- 完播高但互动弱：冲突看完即忘；检查人物是否没有真正失去东西，结尾是否没有可争辩的选择。
- 复播集中在某一拍：保留该拍的视觉证据、停顿或误判机制，作为下一条的单变量假设。
- 评论只猜世界观：资料谜题盖过人物欲望；下一条减少设定解释，增加交易与选择。
