# 电影 vs 短剧：心法与执行

`creative_mode` 只有两个值：`cinema`（电影）与 `short_drama`（短剧）；旧写法 `film`／`story_mode=film` 一律归一为 `cinema`。它决定叙事、台词、镜头、节奏、声音五个维度怎么想、怎么做，**不**决定画幅、时长、预算或交付模式。

先说三条容易混的边界：

- **画幅与模式正交**：竖屏 `9:16` 可以拍慢电影，横屏 `16:9` 也可以拍强冲突短剧。画幅按发布面推导（见 SKILL.md `### 默认假设`），模式按这条内容靠什么让人看下去来定。
- **短时长不禁止慢节奏**：实拍对照样片中 10 秒竖屏单镜慢观察，镜头只做一个推近和一次停顿，照样成立。时长短只意味着要更早让观众看懂利害，不意味着必须快切。
- **两种模式都过张力门**：形式自由，张力不自由。电影的张力可以藏在潜台词和空间里，短剧的张力摆在台面上；八行张力项（见 [dramatic-tension-engine.md](dramatic-tension-engine.md)）两边都要填出证据。

用户没说模式时，按题材与观看场景推断一个，写进 `### 默认假设` 并标「可改」；用户说了「电影感」不自动等于 `cinema`——它也可能只是要短剧镜头更讲究，先按 [prompt-contract.md](prompt-contract.md) 把形容词翻成机位、光和表演。

## 1. 叙事结构与因果

| | `cinema` | `short_drama` |
|---|---|---|
| 心法 | 冰山留白：观众看到的比人物说出的多，情绪靠空间和时间流变累积；揭示可以延迟，答案可以留在画外 | 每一刻都要有可失去的东西摆在台面：谁想要什么、谁挡着、输了丢什么，在最早可读时刻就看得懂 |
| 执行 | 一场戏允许只有一个转折；用前景物件、站位变化、光线变化记录关系微变；延迟揭示必须在前文埋下可回看的物证 | `OPEN ON ACTION`：0–2s 内画面已在冲突动作中，利害可见（写法见 [seedance-first-frame-action.md](seedance-first-frame-action.md)）；权力差要翻面——谁占上风在一场内至少换一次手；每 10–15s 至少一次升级或反转 |
| 常见误用 | 把「什么都没发生」当留白；冰山下面没有冰 | 把吵架当冲突；反转靠新登场的人或突然冒出的证据，前文没埋 |

升级和反转的密度是短剧的执行目标，不是电影的失败标准；电影一场戏只升级一次也合格，只要那一次是挣来的。

## 2. 台词与知情边界

| | `cinema` | `short_drama` |
|---|---|---|
| 心法 | 人物说的和想的不一样；沉默、停顿、答非所问本身就是台词 | 每句话都是一个动作：说给谁、要从对方那里拿到什么、凭什么筹码 |
| 执行 | 潜台词优先；允许画外接话（声音先到、人后到）；整场纯动作哑剧合法 | 每句台词在镜头表里标 `speaker -> listener`、此刻筹码与知情边界（他知道什么、以为什么、不知道什么）；Simplified JSON 的 `audio` 里写成 `说话者（语气，对听者）：台词` |
| 禁区 | 用台词复述画面已经交代的事 | 打破第四面墙的元台词：「上集」「下集」「观众」「大家」「点赞关注」一律不进人物嘴里；人物不能说出他此刻不可能知道的信息 |

知情边界只用来防止人物做出不可能的反应，不写进 prompt 当旁白；模型拿到的是可演的语气括号和动作（见 [prompt-contract.md](prompt-contract.md)「对白字符串写法」）。

## 3. 镜头与空间调度

| | `cinema` | `short_drama` |
|---|---|---|
| 心法 | 镜头运动要有动机：人物移动、视线转移或信息出现才推拉跟摇；空间本身讲故事 | 小屏上看清脸、手和证据；观众在三秒内必须知道谁在跟谁对抗 |
| 执行 | 动机推拉与跟拍；深焦让前景遮挡物和背景人物同时可读；一镜到底合法（`continuous_block`） | 脸部近景与手部特写为主；L-R 轴线固定、视线锁定在对手身上；台词后切反应镜；关键道具给证据特写 |
| 风险控制 | 长镜头里动作过密照样会崩：一镜内主动作超过一个就先过代表镜 | 单镜动作过密（一条里塞两个以上主动作）就拆镜；被遮挡的肢体不驱动运动——首帧看不见的手不能在本镜里突然抬起或拿东西，要用就先在首帧露出来，或拆成新镜 |

遮挡肢体规则两种模式都适用，短剧手部特写多，更容易踩。具体运镜词汇与五槽写法见 [storyboard-camera-direction.md](storyboard-camera-direction.md)。

## 4. 节奏与切点

| | `cinema` | `short_drama` |
|---|---|---|
| 心法 | 让镜头呼吸：情绪落地之后再切 | 零废帧：每一帧都在推进，切点卡在动作上 |
| 执行 | ASL（平均镜头时长）目标 5–10s；镜尾物理 hold ≥ 1.2s 给剪辑；J-cut／L-cut 声桥跨切点 | ASL 目标 2.5–5s；Cut on Action，动作开始后切进、完成前切出；台词之间留 ≥ 0.4s 气口，不把对白贴死 |

ASL = 段落总时长 ÷ 镜头数。传入 `--cutlist <cut.otio>` 时，`eval_harness.py media-qc --creative-mode <cinema|short_drama> --cutlist <cut.otio> --metadata <meta.json>` 自动计算 `shot_count` 与 `asl_s`：偏离目标区间时发 `ASL_PACING_REVIEW`（短剧单镜超上限另发 `LONG_HOLD_REVIEW`）软提示，不单独阻断交付；镜尾物理 hold 与台词气口由剪辑师在连续回放中人工复核。只有 `--metadata` 显式锁定 `locked_one_take: true` 或 `hard_duration_s`、而成片违背锁定时才触发 `ONE_TAKE_LOCK_BROKEN`／`ONE_TAKE_UNVERIFIED`／`HARD_DURATION_MISMATCH` 硬阻断。区间是工艺目标，不是平台算法规律。

## 5. 声音与字幕

| | `cinema` | `short_drama` |
|---|---|---|
| 心法 | 声音建空间：房间底噪、呼吸、物理拟音让画面可信 | 声音推情绪：对白清楚、配乐托情绪但永远给对白让路 |
| 执行 | 房间底噪 + 呼吸 + 接触拟音三层打底；允许 `<0.35s` 的短促机械拟音（卡扣、开关）；禁花字和贴纸；无字幕或极简底部电影字幕 | 高表现力配音：ElevenLabs 或已验证的原生中文口播；配乐对对白做 sidechain 避让；移动端安全区内烧录中文字幕，相邻两条 `end[i] <= start[i+1] - 0.08s` 零重叠，整条 cue `<= 24` 字 |
| 两边都禁 | `>= 0.5s` 的持续窄带合成嗡鸣或正弦／锯齿波假配乐；`video_clips`／`full_film` 里用 `edge-tts`／`espeak` 读对白 | 同左 |

响度、stem 审计与命令见 [post-production.md](post-production.md)；连续观看与四栏判定见 [production-qc.md](production-qc.md)；ducking 参数见 [audio-music-ducking.md](audio-music-ducking.md)。

## 同一前提，两种拍法

**前提**：雨夜旧档案室。林夏来取父亲留下的一把黄铜钥匙；看守老周不肯给。

### 创作选择对照

| 维度 | `cinema` 版 | `short_drama` 版 |
|---|---|---|
| 叙事 | 一个 12 秒长镜：老周装作在找，钥匙其实一直在他毛衣口袋里，观众先于林夏看见；林夏最后看见了，没说破 | 四镜约 14 秒：开场按抽屉 → 老周亮筹码 → 林夏拿出借条翻盘 → 老周交钥匙却留一句钩子 |
| 张力 | 想要：林夏要钥匙；阻力：老周装傻；代价：钥匙后的东西今晚就要被清走；转折：口袋里的钥匙露了一角；结尾：她不揭穿，转身等 | 想要：同左；阻力：老周说钥匙抵了她爸的债；代价：同左；转折：林夏左手一直捏着的借条（S1 首帧已可见）证明债已还清；结尾钩子：「这把钥匙，开的不是柜子。」 |
| 台词 | 只有一句：老周（不抬头）：「那年的柜子早清了。」其余靠沉默和视线 | 每句标 `speaker -> listener`：S1 林夏→老周「钥匙给我。」S2 老周→林夏「你爸欠的，钥匙抵了。」S3 林夏→老周「他还清了，你签的字。」S4 老周→林夏「这把钥匙，开的不是柜子。」 |
| 知情边界 | 老周知道林夏为何而来；林夏不知道钥匙就在眼前，直到最后两秒 | S2 老周以为林夏不知道借条已还；S3 起林夏占有信息优势；S4 老周重新拿回信息差 |
| 镜头 | 深焦中景，前景老周的背和口袋，中景林夏；一次缓推，停在口袋 | S1 手部特写→双人近景；S2 老周近景；S3 借条证据特写；S4 老周近景推到眼睛 |
| 节奏 | ASL 12s，镜尾 hold 2s | ASL 约 3.5s（S1 按通道边界生成 4s，剪辑净可用段 `usable 0–3.5s`），cut on action |
| 声音 | 雨声、翻纸声、远处一声开关卡扣（短于 0.35s）；无配乐；无字幕 | 抽屉撞停闷响开场；S3 起低频配乐进，对白处避让；底部安全区中文字幕 |

## 与校验和 harness 的接口

- Simplified JSON 的 `mode` 字段可选；填了就随规格进入编译，`eval_harness.py media-qc --creative-mode <cinema|short_drama> --cutlist <cut.otio> --metadata <meta.json>` 结合剪辑表与锁定元数据区分机检硬拦截、软提示与人工复核。
- 机检硬拦截（两边一致）：张力门、元台词破墙（`META_DIALOGUE_BREAKS_FOURTH_WALL`）、说话者知情越界（`SPEAKER_KNOWLEDGE_VIOLATION`）、字幕重叠或整条超 24 字、`>= 0.5s` 持续合成嗡鸣、`edge-tts`／`espeak` 机器对白来源，以及 `--metadata` 显式锁定 `locked_one_take`／`hard_duration_s` 时的违锁。
- 机检软提示与人工复核：预检中的疑似遮挡肢体动作 `OCCLUDED_LIMB_ACTION`、短剧静默长镜 `SILENT_HOLD_PACING_REVIEW`、`OPEN_ON_ACTION_REVIEW` 默认发 warning（仅在规则升级或显式锁定/像素穿帮确认后转硬阻断）；`--cutlist` 测出的 ASL 偏离（`ASL_PACING_REVIEW`）与短剧超长单镜（`LONG_HOLD_REVIEW`）只出编辑建议；镜尾 hold 稳定度、台词气口与移动端字幕安全区由人工连续回放复核。
