# 适用范围、证据分级与内容边界

- Version: 7.0.1
- SOP: 3.0
- Author: Enzo (https://blog.enzocreative.me)

## 适用范围

`seedance-prompt-gen` 是专为 AI 短剧与叙事短片创作而生的全流程制作工艺 Skill，覆盖：

- 选题雷达、剧本张力八项硬门与对白表达审校；
- 交付模式（`prompt_only` / `images_only` / `video_clips` / `full_film`）× 创作模式（`cinema` / `short_drama`）路由与 `drama_next.py` 状态机推进；
- 2D 白模站位板、交互式 3D 导演台（`tools/stage-desk/`）与按需 Blender 预演，以及人工确认码门禁；
- Simplified JSON 用户面模板、NBP v2 IR 与多目标方言编译器（`render_nbp_adapter.py`）；
- 棕色地带素材对账、试价→草稿→成片台账（`ledger_submit.py`）、L0/L1 错题预筛与确定性声画后期、多平台 AIGC 标识合规。

## 证据优先级与时效边界

1. **实时架构与官方文档优先**：任何模型支持的参数、分辨率、参考图限额、时长与定价均以当次真实 `model list` / `model get` 或官方有效文档为准；过期观察须重新核验或标为 `TODO_VERIFY_LIVE`。
2. **实测像素与回放验收**：仅文件生成成功不构成交付证据；成片验收依赖本地解码、`ffprobe` 流检查、接触表抽查与音画同步核验。
3. **创作心法与工具能力分离**：戏剧张力、调度与对白工艺只服务叙事表达，不覆盖特定模型或平台的技术限制；榜单或单次经验不得伪装成永久规律。

## 安全与合规边界

- **上下文隔离**：创作只读取当前任务 brief、用户提供素材与本 Skill 参考，不将无关背景或外部历史记忆带入角色与剧情。
- **机制借鉴与知识产权边界**：拆解公开样片或剧集时仅提炼结构机制与视听语法，不复制既有作品的人物命名、标志性台词、道具与镜头序列。
- **凭证最小暴露原则**：工具与环境探测脚本仅检查环境变量名或登录配置文件是否存在，绝不读取、存储或回显任何密钥或令牌原文。
