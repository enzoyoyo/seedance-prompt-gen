# 目标平台包装与分轨交付

仅在用户要发布产物时加载。`target_platforms` 只包含用户指定或当前项目实际要发布的平台；单平台不强建三端资产，多平台才分别导出。抖音、TikTok、YouTube Shorts 是已知示例，不是固定集合；不要用一份带死字幕的文件横发多个目标端。

## 发布快照门

本文件的时长、画幅、封面、音乐与产品入口数字只保留为
**2026-08-24 历史包装快照**，不设统一 14 天过期线，也不自动续期。
规则与披露 claim 的生效窗口、正文可用性和 revision 由
[`platform-evidence-ledger.jsonl`](platform-evidence-ledger.jsonl) 逐条判断；
人读边界见 [`2026-platform-evidence.md`](2026-platform-evidence.md)。历史
包装参数仍须在目标平台、市场、产品模式和账号上 live 核验。

发布前打开目标地区的官方创作者中心/帮助页，核对：

```text
duration_and_classification / aspect_ratio / safe_area / cover
caption_and_music_rights / synthetic_media_disclosure
upload_metadata / series_or_paid-drama_rules
```

无法核对时标 `TODO_VERIFY_LIVE`，不以运营文章的算法阈值替代官方规则。

## 母片到多画幅切片

### 1. 保留干净母片

母片不烧平台水印、互动按钮或永久字幕；保留最高质量画面、独立音轨、字幕源文件、封面源图和镜头边界。多平台项目在分镜阶段同时预留竖裁安全构图，不能等成片后盲目居中裁切。

常见派生链可从横屏母片重构竖屏、方形或其他当前目标版本；`16:9 / 2.39:1 / 9:16 / 1:1 / 4:5` 只是制作示例，不证明目标平台当前接受对应枚举。若竖屏是主发行端，应先保护竖屏构图，不能为了横屏母片牺牲人物可读性。

### 2. 逐镜重构，而非全片一键裁

按镜头选择：

- 主体跟踪重裁：人物移动时关键帧重定位；
- 双人重排：必要时改为上下/分屏或切反应镜，避免裁掉一方；
- 道具特写重做：保证剧情证据与品牌文字仍可读；
- 宽景替换：横屏建立镜头不能直接压成竖屏小人，另做近景覆盖；
- 文字重排：字幕、身份牌、CTA 按平台安全区重新排版；
- 结尾重组：按已选平台当前入口选择循环、续集/付费动作、系列入口或其他真实 CTA，不为未选平台制作占位版本。

目标画幅与像素尺寸逐项 live 核验；导出前只使用目标平台当前接受的枚举。

### 3. 每条成片重新验收

智能重构只能给初稿。逐条完整播放，检查脸和核心道具是否持续在安全区、字幕是否遮表演、cut 是否因重裁而跳位、封面是否兑现开场、结尾动作是否仍成立。多平台分发（如竖屏剧集、横屏长版、图文预热封面卡）交付前须逐文件用 `ffprobe` 与图像尺寸回读核验成片流像素宽高比、封面图比例（如 9:16／16:9／3:4）与无意外黑边，禁止拿单一烧录字幕版改文件名横发多端。

## 中国 AI 微短剧逐集标识

Ledger 只记录了一次**单来源官方正文已读**：第 34 条的逐集明显标识
命题，以及第 17 条的分类审核/许可、批准文件或节目编号命题。它们
没有 normalized official-body hash，也没有当前申报或发布入口收据；
因此只可用于规划，不能据此放行发布。
- 单集定义、分类备案/许可、金额或题材分层、角标样式与隐式元数据细则可能继续调整。
- Ledger 只保留“每集明显位置”的义务语义，不推定固定文案、像素、
  持续时长、片头/持续角标样式或 App 字段。

发布前逐集检查：

- [ ] 当前法规原文与目标平台细则已重新打开并记录日期；
- [ ] 当前规则与目标平台实际呈现共同确认了可见标识实现；
- [ ] 当前 actor、账号、市场、产品模式的 AIGC 控件名称、位置与字段已 live 核验；Douyin 具体字段仍是 `TODO_VERIFY_LIVE`；
- [ ] 备案号、许可证或分类要求已核；
- [ ] 政军外、未成年人、医疗等特殊题材已走对应审查；
- [ ] 角色肖像、声音、音乐、字体、素材和 IP 权利可追溯；
- [ ] 发布项目留存可审计的文本/DOM/JSON 收据和 hash；截图、账号名与凭据不写回可复用 Skill；
- [ ] 若细则不可得，标 `TODO_VERIFY_LIVE` 并停止发布，不猜样式。

## 发布前总检

- [ ] 每个已选平台不是同文件改名，时长、封面、标题、字幕与结尾分别处理；单平台没有多余占位资产；
- [ ] 所有平台规则未过期，来源为官方当前页面；
- [ ] 第一帧兑现封面承诺，字幕不遮脸、不遮道具、不越安全区；
- [ ] 音乐许可、AIGC 披露、备案/许可和逐集标识已闭环；
- [ ] 每个平台完整播放并通过技术/视觉/听觉 QC；
- [ ] 信号复盘会回写 [trend-research.md](trend-research.md)，成片检查并入 [production-qc.md](production-qc.md)。
